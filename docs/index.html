rust_cargo

Pinned, SHA-256 verified Rust toolchains and vendored crate mirrors for darbotlm projects (MXC, bitscoop, scooper). Public, so builds and pipelines need no secrets.

What's published

ArtifactWhere
Rust toolchain darbot-1.100.0 (rustc 1.100.0, 0ef1bc386)toolchain-1.100.0, manifest toolchain/darbot-1.100.0.json
Hostsx86_64 / aarch64 Windows (msvc), x86_64 Linux, aarch64 / x86_64 macOS
Cross targets (rust-std)+ aarch64-unknown-linux-gnu
Vendored crates.io sourcescrates, keyed by Cargo.lock hash, index crates/index.json

Toolchain packages are byte-identical to the official static.rust-lang.org dist tarballs; each one's upstream URL and hash is in the manifest.

Install the toolchain

git clone --depth 1 https://github.com/DarbotLM/rust_cargo.git
./rust_cargo/scripts/Install-RustCargoToolchain.ps1 -Toolchain darbot-1.100.0 -AdditionalTargets aarch64-pc-windows-msvc
cargo +darbot-1.100.0 build --locked
./rust_cargo/scripts/install-rustcargo-toolchain.sh darbot-1.100.0 aarch64-unknown-linux-gnu

Build offline from the crate mirror

./rust_cargo/scripts/Use-RustCargoCrates.ps1 -LockFile src/Cargo.lock -ConfigFile .cargo/config.toml
cargo build --locked --offline

Azure Pipelines

steps:
  - template: Rust.Toolchain.RustCargo.yml@self
    parameters:
      toolchain: 'darbot-1.100.0'
  - template: Cargo.Setup.RustCargo.yml@self

Templates are in azure-pipelines/. They replace the ms-prod-* toolchain and the cargo registry on Mxc-Azure-Feed.
